## Summary

Add copy-mode template insertion, creating fresh nodes and internal edges from template snapshots, with placement, annotations and per-node shape overrides. Copy is the default; reference mode remains available. Staged sessions keep creations in their staged layer.

If a later write fails, insertion attempts rollback in reverse order. Rollback is best-effort: failures are logged, may leave residual changes, and do not replace the original error. Staged creation events are held until the presentation write succeeds, so failed insertions broadcast no operations.
