## 2025-02-14 - Accessibility improvements for FloatingSearch icon and input
**Learning:** The FloatingSearch input was missing an explicit `aria-label`, meaning screen readers would fallback to reading the placeholder attribute. The decorative Search icon was missing `aria-hidden="true"`, which can cause screen readers to announce it unnecessarily. While translations are accessible via the `useI18n` hook, it's critical to verify the translation keys (e.g., `search_panel_title`) exist before using them.
**Action:** Always add explicit `aria-label` attributes to form inputs, even if a placeholder is present, to ensure robust screen reader support. Always add `aria-hidden="true"` to decorative icons within interactive elements. When applying translations, check the corresponding JSON files in the `i18n` directory to confirm the key is defined.
