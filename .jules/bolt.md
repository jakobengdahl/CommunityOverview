## 2025-02-20 - Batching edge lookups with NetworkX
**Learning:** In `backend/core/storage.py`, methods that retrieve incident edges from a NetworkX `MultiDiGraph` (like `get_incident_edges`) can experience O(N) lookup degradation if queried inside a Python loop (e.g., `for node_id in node_ids: graph.out_edges(node_id)`). NetworkX allows passing a collection of node IDs directly to `out_edges()` and `in_edges()` to batch the retrieval inside its C-optimized internal structures.
**Action:** Always prefer passing an iterable of node IDs directly to NetworkX `out_edges` and `in_edges` instead of looping over the IDs in Python. Ensure `out_edges` is called first, followed by `in_edges` to maintain iteration order, and deduplicate edges by ID since self-loops will appear in both.
