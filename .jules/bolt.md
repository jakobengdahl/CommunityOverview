## 2026-10-31 - NetworkX out_edges/in_edges list batching does not yield measurable performance gain
**Learning:** Passing a node list to networkx `out_edges` / `in_edges` loops over the nodes internally just as the original Python loop did. It provides no measurable performance gain and changes the iteration order in which edges are returned. An attempt to optimize `get_incident_edges` this way was rejected for these reasons.
**Action:** Do not attempt to batch list inputs to NetworkX `out_edges`/`in_edges` to achieve performance gains, as the internal implementation does not provide a meaningful C-optimized speedup and alters the expected output order.
