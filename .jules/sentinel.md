## 2025-02-28 - Fix SSRF Vulnerability in MCP Tool Info Discovery
**Vulnerability:** Server-Side Request Forgery (SSRF) in `MCPLoader._connect_http` where the `info_url` was fetched using `httpx.get` with `follow_redirects=True` without validating the initial URL or any subsequent redirect hops. This allowed an external server to redirect internal agent traffic to private internal endpoints (e.g., AWS Metadata Endpoint, localhost).
**Learning:** While the application had an existing `is_safe_url` guard for webhooks and image fetches, it wasn't applied to the tool info discovery endpoint for MCP HTTP servers. `httpx.get` with `follow_redirects=True` blindly follows HTTP redirects, rendering any initial URL validation useless if the target server issues a malicious 302 redirect.
**Prevention:** When fetching external URLs using `httpx`, always use a `with httpx.Client(..., follow_redirects=False) as client:` context manager. Manually follow redirects in a loop, validating both the initial URL and the `Location` header of each redirect hop against `is_safe_url` before issuing the subsequent request.
