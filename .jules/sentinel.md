## 2025-02-23 - Strict Regular Expression Path Matching in Authentication Middleware\n**Vulnerability:** A wildcard path traversal vulnerability allowed authentication bypass for session endpoints.\n**Learning:** The usage of `.startswith()` and `.endswith()` for request path evaluation allowed for URL structures like `/api/sessions/hack/stream/bypass` or `/api/sessions/hack/bypass/stream` to bypass authentication.\n**Prevention:** Strictly enforce dynamic route parameters using regular expression matching (`re.match`) anchored at the beginning and end (`^` and `$`) with an escaped dynamic prefix (`re.escape`).
